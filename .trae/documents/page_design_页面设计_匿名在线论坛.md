# 页面设计说明（桌面端优先）

## 全局规范（所有页面通用）
- Layout：桌面端使用 12 栅格（CSS Grid）+ 局部 Flex；主容器 max-width 1120px，左右留白自适应；移动端断点 768px 以下改为单列堆叠。
- Global Styles（Design Tokens）
  - 背景：#0B1020（深色）或 #F7F8FA（浅色，二选一实现）
  - 内容卡片：白底/深灰底，圆角 12px，阴影轻量
  - 主色：#3B82F6；强调色：#22C55E；危险色：#EF4444
  - 字体：系统字体栈；字号：12/14/16/20/24
  - 按钮：主按钮实心，hover 提亮 6%；次按钮描边；禁用态降低不透明度
  - 链接：主色下划线 hover 显示
- Interaction：提交表单时显示 loading；错误提示使用表单下方小字；列表加载更多使用 skeleton。
- SEO/OG（公共页）：title 以“站点名 - 页面名”；description 简述“匿名讨论与意见箱”；OG 使用站点默认封面。

## 1) 论坛首页（话题列表）
### Meta Information
- title：匿名论坛 - 话题
- description：匿名参与话题讨论，并可提交意见给管理员。

### Page Structure
- 顶部导航（固定或随滚动收缩）
- 主内容区：左侧话题列表（主列），右侧信息栏（侧列，桌面端）

### Sections & Components
1. 顶部导航栏（Flex）
   - 左：站点 Logo/名称（点击回首页）
   - 中：导航链接（话题 / 提交意见 / 管理员）
   - 右：可选“主题切换”（不影响核心功能，可不做）
2. 话题列表区（Card List）
   - 列表项：标题、发布时间、回帖数
   - 点击整行进入话题详情
   - 底部：分页或“加载更多”按钮
3. 创建话题模块（Card）
   - 输入框：标题（单行）、正文（多行）
   - 提交按钮：发布
   - 校验：标题/正文必填；失败提示
4. 侧栏（桌面端显示，移动端下移到列表后）
   - “提交意见”引导卡：一句说明 + 按钮跳转 /opinion

## 2) 话题详情页
### Meta Information
- title：匿名论坛 - 话题详情
- description：查看与参与当前话题的匿名讨论。

### Page Structure
- 顶部导航
- 主内容：话题卡 + 回帖列表 + 回帖编辑器

### Sections & Components
1. 面包屑/返回
   - “← 返回话题列表”
2. 话题展示卡（Card）
   - 标题（H1）、正文（富文本不做，纯文本换行）、发布时间
3. 回帖列表（Stack）
   - 每条回帖：正文、发布时间
   - 列表底部：分页/加载更多
4. 发布回帖（Composer）
   - 多行输入框 + 提交按钮
   - 提交成功后：清空输入并将新回帖追加到列表末尾

## 3) 提交意见页（仅管理员可查看）
### Meta Information
- title：匿名论坛 - 提交意见
- description：匿名提交意见，内容仅管理员可见。

### Page Structure
- 顶部导航
- 居中单列表单（max-width 720px）

### Sections & Components
1. 说明区（Info Banner）
   - 文案：不记录用户信息；意见仅管理员可见；提交后无法查看历史记录
2. 意见表单（Form Card）
   - 多行输入框：意见内容（必填）
   - 提交按钮：发送
   - 状态：loading、成功回执（例如“已收到你的意见”）、失败重试

## 4) 管理员意见查看页（含登录）
### Meta Information
- title：匿名论坛 - 管理员
- description：管理员查看匿名意见（只读）。

### Page Structure
- 未登录：登录卡片居中
- 已登录：两栏布局（左列表右详情）

### Sections & Components
1. 管理员登录（Auth Card）
   - 邮箱、密码输入
   - 登录按钮
   - 错误提示：账号或密码错误
2. 意见列表（Left Pane）
   - 搜索/筛选：按时间（最近/最早）
   - 列表项：提交时间 + 前 50 字摘要
   - 点击后选中并在右侧显示详情
3. 意见详情（Right Pane，只读）
   - 完整内容、提交时间
   - 仅提供“复制内容”按钮（可选）
4. 权限提示（强约束 UI）
   - 页面不提供任何“发帖/回帖/提交意见”入口
   - 若管理员尝试访问发帖相关路由，前端提示“管理员账号仅可查看意见”并跳回 /admin/opinions
